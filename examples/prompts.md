# Example Prompts

These prompts can be copied directly into Codex.

## Illustration Planning Only

```text
Use $ian-xiaohei-illustrations. Do not generate images yet.
Analyze the article below and identify about 5 places where illustrations would be useful.
For each image, specify:
- Where it should appear
- The theme
- The core idea
- The structure type
- What Xiaohei is doing in the image
- Suggested visual elements
- Suggested short English labels

<Paste article>
```

## Article Body Illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 strange Xiaohei body illustrations for the article below.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, and a few short red/orange/blue handwritten English notes.
Each image should express only one core structure. Do not make PPT-style infographics or cute cartoons.

<Paste article>
```

## Long-Form Illustration Strategy

```text
Use $ian-xiaohei-illustrations to create an illustration strategy for this long article.
Do not distribute images evenly. Only choose cognitive anchors: core judgment, input-output loop, before/after contrast, common trap, or handoff path.
Default to 6-8 images. Output the shot list first; do not generate images yet.

<Paste article>
```

## One Image for One Idea

```text
Use $ian-xiaohei-illustrations to generate one 16:9 article illustration for this idea:

Trust is not claimed out loud; it is built by laying down one piece of evidence after another.

The image should feel strange but clean. Xiaohei must carry the core action.
Use no more than 5 short English labels.
```

## Workflow Theme

```text
Use $ian-xiaohei-illustrations to generate one image for: turning one raw material into three kinds of content: traffic, trust, and conversion.
Do not draw a formal flowchart, and do not copy the old one-fish-many-uses example.
Invent a new low-tech metaphor and make Xiaohei part of the core action.
```

## Image Edit: Remove Title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the top-left title "Workflow" and its underline. Preserve everything else.
Do not add any new text or objects.
```

## Image Edit: Make Xiaohei More Involved

```text
Use $ian-xiaohei-illustrations. This image is going in the right direction, but Xiaohei feels decorative.
Regenerate it with the same core meaning: make Xiaohei the person actually driving the structure.
Make the scene stranger, but keep it pure white, clean, and sparse.
```

## Generate Style Samples

```text
Use $ian-xiaohei-illustrations to output 5 Xiaohei body-illustration samples with different themes.
The themes should cover: information overload, product validation, content compounding, one-person company, and trust building.
Generate each image separately; do not combine them into one image.
```
